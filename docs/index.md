# Selling Digital Products: A Plain-English Manual for a One-Person LLC

*By Dylan Asdale · Asdale Dynamics, LLC*

## Who this is for

You already write books. You have a one-person LLC, a story readers actually like,
and a nagging feeling that a book is a weirdly narrow container for what you know.
This manual is the friend that explains the rest — the templates, printables,
planners, prompt packs, and small tools that can sit next to your books and earn
money while you sleep.

It is written like everything we publish: plain English, step by step, never
condescending. If a fee is "about ten percent," we say that instead of burying you
in decimals. If a platform could ban you for a listing mistake, we say that too.

## The one-page philosophy

Before any chapter, here is the whole business in five sentences:

1. Make things that take an afternoon to produce and solve one narrow problem for
   someone who already exists.
2. Sell them where those buyers already shop (Etsy) *and* on a storefront you
   control (Gumroad or Ko-fi), so you learn both sides of the fee trade.
3. Write listings and previews that show exactly what is inside — honesty is a
   feature in a six-slide carousel.
4. Put a plain-English license with every file so generous buyers stay legal and
   greedy buyers have nowhere to hide.
5. Collect email addresses from everywhere, because your list is the only asset
   no marketplace can turn off.

## How to use this folder

- Every markdown file in `docs/` becomes an HTML page when you run `npm run build`.
- Run `npm test` to check that the build and its converter still behave.
- Run `npm start` to preview the site at <http://127.0.0.1:4173> — no internet
  needed, nothing gets uploaded anywhere.

## A note, not legal or tax advice

We are writers, not lawyers or accountants. Everything here is practical
experience with round numbers attached. Where fees matter, verify current rates
on the platform's own fee page before you price anything, because they change
more often than this guide does.
