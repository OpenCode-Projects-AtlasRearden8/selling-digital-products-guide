# STATUS.md — selling-digital-products-guide

**Date:** 2026-10-31
**Owner:** Asdale Dynamics, LLC (work by Dylan Asdale)
**State:** complete, tested, committed locally (no remote, nothing published)

## What was built

A local-first manual for a one-person LLC selling digital products directly:

- **Markdown guide (`docs/`, 11 files)**
  - `index.md` — start here: the five-sentence philosophy and companion-guide
    map (mentions *craft-fair-seller-handbook* and
    *publishing-beyond-kdp-guide*).
  - `01-what-to-make.md` — templates, printables, planners; eight-row product
    idea table; what to skip; "cousin product" strategy.
  - `02-platforms-and-fee-math.md` — Etsy vs Gumroad vs Ko-fi with round-number
    receipts ($10 and $25 transactions), a $500/month comparison table, hidden
    costs, pricing implications, and a 120-second decision rule.
  - `03-listing-copy-and-previews.md` — five-second listing architecture, a
    six-slide preview carousel recipe, mockup and privacy ground rules.
  - `04-licenses-in-plain-english.md` — personal vs commercial tiers, a
    copy-paste license template, education-only wording for health-shaped
    products, an FAQ.
  - `05-copy-theft-response.md` — verify → polite note → platform report →
    DMCA-style notice ladder; loss-based triage table; theft-boring
    preventive habits; none of it needs a lawyer.
  - `06-seasonal-bundles.md` — seasonal demand calendar, 60–70% bundle math,
    dated-product refresh strategy, three launch slots per year.
  - `07-when-to-leave-marketplaces.md` — readiness signals, the math at
    $3,000/month, migration checklist, three own-store options.
  - `scorecard.md` — product scorecard worksheet scored 1–40 with verdict
    bands and a blank copy.
  - `launch-checklist.md` — 120+ tick-box items from two weeks before launch
    to steady state.
  - `glossary.md` — 24 plain-English definitions.

- **Static HTML site** generated by `build.js` (Node stdlib only — no npm
  dependencies, no network): 11 self-contained pages in `site/` with shared
  header, page navigation, prev/next links, and a dark-on-cream stylesheet.
  Website output is git-ignored as a build artifact.

- **Dependency-free markdown renderer (`md.js`)** supporting the feature
  subset the docs use: headings, paragraphs, wrapped-line joining, lists with
  checkboxes, tables, fenced code, blockquotes, hr, inline bold/italic/code/
  links, with full HTML escaping (XSS-safe output).

- **Local preview server (`serve.js`)** — binds to 127.0.0.1 only, serves
  `site/`, 404s on missing paths, blocks path traversal.

- **Tests (`tests/build.test.js`)** — 23 node:test cases: converter unit
  tests (including regressions for the bugs found during verification:
  split paragraphs, per-line lists, per-line blockquotes, escaped script
  tags), build integration (page inventory, internal link resolution,
  footer/license presence, no script tags), and repo hygiene (exact LICENSE
  line, README credit, no secrets in docs, every doc mapped to a build page).

- **LICENSE** — MIT, copyright line exactly: `Copyright (c) 2026 Asdale
  Dynamics, LLC`. **README.md** credits Asdale Dynamics, LLC.

## How to run

```sh
npm run build   # renders docs/*.md into site/
npm test        # 23 tests
npm start       # local preview at http://127.0.0.1:4173 (127.0.0.1 only)
```

Requires Node ≥ 18 (tested on Node 20.19.2). No internet needed for any step.

## Known gaps / honest notes

- **Fee figures are rounded and time-stamped.** Etsy/Gumroad/Ko-fi fees change
  regularly; chapter 2 says so explicitly, but a future pass should re-verify.
- **The converter covers the markdown subset used by these docs** — no
  images, nested lists, or reference-style links. Extending `md.js` would need
  new tests.
- **No preview images ship with this repo** (the site is text-only); the
  six-slide carousel in chapter 3 is a recipe, not rendered assets.
- **No search or dark mode** on the site; deliberate trade for zero-JS,
  zero-dependency output.
